The four issues v1 raised on the App Router redesign were addressed in a single fix commit (`1d24a0d`): the home hero video no longer autoplays and is now driven by `SiteMotion` under the reduced-motion preference, the services industries grid was rebuilt around an explicit name+descriptor list guarded by a build-time assertion, the contact submit gate kept its behaviour with an inline justification, and the stale `MotionControl` comment in `ProjectVisual.css` was corrected to `SiteMotion`. Watch for: nothing blocking. The hero video's playback tracks the reduced-motion query and route changes but not the ambient-motion toggle (**confirmed**) — this matches the hardcoded `AUTOPLAY_HERO_VIDEO` default and the prototype's `autoplayHeroVideo` behaviour, so it is by-design, not a regression.

**Verdict**: APPROVED

## High-level view

The v1 blocker is closed. The hero `<video>` lost its `autoPlay` attribute and gained `data-hero-video`; `SiteMotion` now selects it, forces `muted`, and pauses when reduced motion is requested (or autoplay is off) while calling `play().catch()` otherwise. Because the play/pause logic sits ahead of the reduced-motion early-return in the scroll effect and the effect is keyed on `reduced`, flipping the OS preference at runtime re-pauses the video. Without JS the element carries no autoplay, so scripts-off visitors see the `.home-hero-frame` CSS gradient as the first-frame fallback — no-JS-safe by construction, and the absence of a poster is a deliberate asset-rule choice.

The industries grid fragility is resolved properly. The eight tiles are now a single typed `{ name, descriptor }[]` literal, so a descriptor can no longer fall through to an empty string. A build-time loop asserts the first seven tile names still equal the leading seven entries of `industries.ts` in order and throws a descriptive error on drift; the eighth slot ("Real Estate") is intentionally outside that check because it does not come from the content source's first seven.

The contact submit gate is unchanged in behaviour but now documents why: submission is entirely client-side (a mailto draft, no server endpoint), so enabling the button before hydration would let a native POST fire against a route that does not exist. The reasoning is sound and the `<noscript>` mailto fallback remains. The `ProjectVisual.css` comment now names `SiteMotion` as the `data-motion` owner.

### Hero video now gated on reduced motion

The `<video>` in `page.tsx` dropped `autoPlay` and kept `loop muted playsInline`, tagged `data-hero-video`. In `SiteMotion` the scroll effect queries that element and, before the `if (reduced) return;` early-return, forces `muted = true` and either pauses (when `reduced || !AUTOPLAY_HERO_VIDEO`) or starts playback via `play().catch()`. The effect's dependency array includes `reduced`, so a runtime change to the OS preference re-runs the block and pauses a playing video rather than leaving it running. The `catch` swallows the autoplay-policy rejection and leaves the video parked on the gradient frame, which is the intended fallback.

```
prefers-reduced-motion: reduce   → SiteMotion pause()             ✓ (was ✗ in v1)
autoplay default (no reduce)     → play().catch() best-effort     ✓
no JavaScript                    → no autoplay attr, gradient frame ✓
```

### Industries grid: assertion replaces the silent-blank path

The v1 shape looked names up in a descriptor map and fell back to `""` on a miss, so a reorder of `industries.ts` could ship a blank descriptor. The rewrite pins name and descriptor together in one literal and derives the tiles from it directly, so `descriptor` is always populated. The guard reads the first seven names from `industries.ts` and throws if any tile name diverges in position. Verified against the content source: its leading seven are Healthcare, Fintech, Logistics, Retail, Ecommerce, Education, BFSI Solutions — exactly the first seven entries of `industryTileSource`, so the assertion passes today and would fire loudly on a future reorder. "Real Estate" (slot 08) is correctly excluded from the check since it is the ninth entry in the content source, not one of the leading seven.
